# Artificial Intelligence – Projects

## Project 1: Lunar Lander (Reactive Agent)

Development of a reactive agent in Python for controlling a spacecraft in the *Lunar Lander* simulation environment.

The project involved:
- Defining perceptions and actions for the agent
- Implementing a rule-based production system for decision-making in a discrete-time environment
- Achieving safe landings under simulation constraints

Basic Artificial Intelligence concepts were applied, particularly reactive agents and production systems, using the Gymnasium framework.

---

## Project 2: Evolution of Lunar Lander (Evolutionary Algorithm)

Extension of the previous project with the implementation of an evolutionary algorithm in Python to optimise controllers for the Lunar Lander agent.

The project focused on:
- Evolving neural networks using genetic operators (selection, crossover, mutation)
- Maximising landing success rate through evolutionary optimisation
- Testing different experimental configurations and parameter settings
- Analysing performance under different conditions, including environments with and without wind

The work included evaluation of evolutionary strategies and their impact on agent performance.
