# Workshop Reservation System

<img src="https://cdn.jsdelivr.net/gh/devicons/devicon/icons/c/c-original.svg" width="60"/>

Procedural Programming Principles 2022/23

## Description

C application for managing workshop reservations, including customers, service slots, reservations, and waiting lists for car wash and maintenance services.

## Features

- Create and manage reservations (wash or maintenance)  
- Create and manage pre-reservations (waiting list)  
- Cancel reservations and automatically promote waiting requests  
- List reservations and pre-reservations by date  
- List all reservations for a specific client  
- Time-slot management (8h–18h schedule constraints)  

## Structure

- Use of structured data and linked lists  
- Separation of data structures in independent files  
- Efficient memory usage with pointer-based management  
- Sorting using auxiliary pointer-based structures  

## Data Persistence

- Data stored in text files  
- Load data at startup  
- Save system state on demand  

## Notes

- Implemented in C  
- Focus on procedural programming concepts  
- Emphasis on correct data structures and memory management
