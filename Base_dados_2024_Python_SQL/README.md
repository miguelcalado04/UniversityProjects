## Introduction
This project was developed within the scope of the **Databases course**, following industry best practices for the design and implementation of a database-centric system.

The goal is to build a **Hospital Management System (HMS)** that centralizes and manages hospital operations such as patients, appointments, surgeries, prescriptions, billing, and reporting through a REST API connected to a PostgreSQL database.

## Objectives
- Design and implement a relational database system
- Develop a REST API in Python for data access and manipulation
- Use SQL and PL/pgSQL for complex queries, triggers, and procedures
- Apply transaction management and concurrency control
- Ensure data integrity, security, and error handling
- Follow a client-server architecture with PostgreSQL as DBMS

## Technologies
- Python
- PostgreSQL
- SQL

## System Overview
The system manages:
- Patients, doctors, nurses, and assistants
- Appointments and surgeries
- Hospitalizations
- Prescriptions and medications
- Billing and payments
- Reports and statistics

## Architecture
- REST API layer (Python server)
- PostgreSQL database (relational model)
- Transactional and concurrent environment
- Trigger-based billing updates and business rules

## Key Features
- User registration and authentication
- Appointment and surgery scheduling
- Prescription management
- Automatic billing via database triggers
- Financial and operational reports
- Concurrency-safe operations
