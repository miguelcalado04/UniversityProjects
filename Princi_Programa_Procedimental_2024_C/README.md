# Patient Management System

Procedural Programming Principles 2023/24

## Description

C application for managing a doctor’s patients and their clinical records. The system stores personal data and health measurements such as blood pressure, weight, and height.

## Features

- Add and remove patients  
- List patients in alphabetical order  
- Display detailed patient information  
- Record clinical data (blood pressure, weight, height)  
- List patients with high blood pressure values  

## Structure

- Use of linked lists to store patients and clinical records  
- Data organized using appropriate structures  
- Efficient memory usage with pointer-based solutions  

## Data Persistence

- Patient and record data stored in text files  
- Data loaded at startup and updated during execution  

## Notes

- Implemented in C  
- Focus on procedural programming and data structures  
- Emphasis on code organization and memory efficiency
