# POO Financial Services (POOFS)

Object-Oriented Programming 2024/25

## Description

POOFS is a Java application for managing clients and invoices. It supports different types of products (food and pharmacy) and calculates VAT according to product type and client location.

## Features

- Create and manage clients  
- Create, edit, and list invoices  
- Detailed invoice view (values with and without VAT)  
- VAT calculation with specific rules (rates, categories, discounts)  
- Import and export invoices from/to text files  
- Statistics (number of invoices/products, total values)

## Structure

The application follows object-oriented principles:

- Use of classes for clients, products, and invoices  
- Inheritance and polymorphism for different product types  
- Encapsulation of data and responsibilities  

## Data Persistence

- Data is saved to a file before exiting  
- Automatically loaded on startup if available
