# POO Financial Services (POOFS)

Object-Oriented Programming 2024/25

## Description

Java application for managing clients and invoices, supporting food and pharmacy products with different VAT rules based on product type and client location.

## Features

- Client and invoice management  
- VAT calculation with specific rules  
- Import/export of invoices  
- Statistics (totals and counts)  

## Notes

- Developed using object-oriented principles (inheritance, polymorphism)  
- Data persistence using files
